# Data

Raw vibration data from the [CWRU Bearing Data Center](https://engineering.case.edu/bearingdatacenter/download-data-file), stored as MATLAB `.mat` files.

**Source of truth:** [`manifest.csv`](manifest.csv), with one row per file: label, fault type, diameter, load, RPM, sampling rate, URL, size and SHA-256.

## Layout

```
data/
├── manifest.csv        # tracked in Git
├── README.md           # tracked in Git
├── raw/                # git-ignored, never edited
│   ├── normal/         #  4 files
│   ├── 12k_drive_end/  # 60 files
│   ├── 48k_drive_end/  # 52 files
│   └── 12k_fan_end/    # 45 files
└── processed/          # git-ignored, generated by src/data
```

161 files, about 688 MB in total. The `path` column in the manifest is relative to `data/raw/`.

## Verify integrity

Run from the repo root. Every line should print `OK`.

```bash
tail -n +2 data/manifest.csv | awk -F, '{print $14"  data/raw/"$4}' | sha256sum -c
```

## Known issues

- The sampling rate of the normal files (97–100) is not stated on the CWRU site. It is `left blank in the manifest` in the manifest until confirmed.
